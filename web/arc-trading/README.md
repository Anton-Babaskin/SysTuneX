# ARC Trading — редизайн сайта (светлая тема)

Статический сайт из четырёх страниц. Без сборки, без зависимостей в репозитории:
открывается как есть, раздаётся любым статическим хостингом, в том числе
GitHub Pages.

```
index.html        главная — слайдер-герой, о компании, 6 товаров, преимущества, контакты
products.html     каталог — все 25 позиций с фильтром по группам
about.html        о компании — чем торгуем, мощности, рынки, как работаем
industries.html   отрасли — шесть секторов с фото, таблица «сектор → позиции»
logistics.html    логистика — способы доставки, условия поставки, документы
quality.html      качество — что фиксируется и когда, сертификаты, спецификации
contact.html      контакты — форма, реквизиты, что указать в запросе
assets/site.css   вся типографика, палитра и компоненты
assets/site.js    слайдер, каталог, анимации, форма
img/              31 изображение, лежат в репозитории (2,4 МБ)
.nojekyll         чтобы GitHub Pages не пропускал файлы через Jekyll
```

## Публикация на GitHub Pages

1. Создай репозиторий и положи содержимое этой папки в его **корень**
   (`index.html` должен лежать рядом с `.git`, не во вложенной папке).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт поднимется на `https://<пользователь>.github.io/<репозиторий>/`.

Все ссылки внутри сайта относительные, так что он одинаково работает и в корне
домена, и в подпапке `/<репозиторий>/`.

Локально:

```
npx http-server -p 8099 -s      # или python3 -m http.server 8099
```

## Дизайн

Палитра `#FFFFFF / #F6F7F9 / #EDEFF2`, единственный акцент — янтарный
`#F5A623` из логотипа, тёмная поверхность `#11101f` (совпадает с фоном
оригинального логотипа) только в футере, кнопках и CTA-блоках.
Шрифты Inter Tight + Inter. Логотип — оригинальный `logo.png` с боевого сайта,
на тёмной скруглённой плашке, потому что в файле непрозрачный тёмный фон.

Жёлтый взят пипеткой из самого логотипа: `#FFC82C`. Им залиты кнопки, точки
слайдера, кольца и всё, где цвет лежит плашкой под тёмным текстом. Тонкие
линии, иконки и слово ARC в заголовке используют `#E5A900` — тот же тон,
затемнённый, иначе на белом фоне он почти не виден.

Картинки лежат в `img/`, пережаты из оригиналов: 8,7 МБ → 2,4 МБ.
Ничего внешнего, кроме шрифтов Google и GSAP/Lenis с CDN.

## Контент

Тексты, названия товаров, цифры мощностей и контакты с боевого сайта
перенесены дословно. На главной каталог показывает **6 позиций**; список
задаётся массивом `FEATURED` в `assets/site.js`, полный каталог из 25 позиций
живёт в `PRODUCTS` там же и выводится на `products.html`.

На экранах уже 700px витрина на главной превращается в горизонтальную
карусель со snap-прокруткой и полосой прогресса под ней; последней картой идёт
переход в полный каталог. «More details» ведёт на `products.html#uN` — страница
доскроллится до нужной позиции и подсветит её.

Страницы `about.html` и `logistics.html` — новый текст, написанный вокруг
фактов с боевого сайта (GOST, мощности, ~600.000 mt в 2023, 20 000 человек в
партнёрской сети, рынки СНГ и Европы). Никаких сертификаций, офисов или цифр,
которых нет на оригинале, там не выдумано.

Слайдер из 4 слайдов, автопрокрутка 7 секунд, Ken Burns-панорамирование,

## Эффекты

Заставка с логотипом показывается один раз за сессию браузера и только на
главной (`sessionStorage`), на внутренних страницах её нет вообще — переходы
мгновенные. Прогресс-бар чтения, кастомный
курсор с magnetic-кнопками, посимвольная анимация заголовка на первом слайде,
параллакс фонов и коллажей, scroll-reveal со стаггером, бегущая строка со всеми
25 товарами, 3D-tilt карточек, FLIP-фильтрация каталога, count-up счётчики,
floating-label форма с состояниями loading → галочка, копирование контактов,
пульсирующий маркер на карте, обводной логотип во всю ширину футера.
`prefers-reduced-motion` глушит всё.

**Ховеры работают только там, где есть настоящий курсор.** Все 35 hover-правил
собраны в один блок `@media (hover:hover) and (pointer:fine)`. На тач-экранах
`:hover` залипает после тапа и оставляет карточки в недожатом состоянии —
вместо этого там короткие `:active`-отклики. Исключение сделано для `.active`
в меню: этот класс не зависит от указателя и вынесен из ховер-селекторов.

Ссылки на CSS и JS идут с версией (`?v=6`) — Pages и Safari кэшируют
агрессивно, без версии правки доезжают через раз. При следующем изменении
ассетов номер надо поднять.

## Что доделать перед продакшеном

1. **Водяные знаки.** Значительная часть исходных фото товаров идёт со стоковыми
   watermark'ами — как минимум `u3` (HRS PLATE), `u5` (STEEL BEAM), `u6`
   (STEEL ANGLE), `u7` (STEEL RODS), `u8` (STEEL MINE STAND), `u13`
   (FERROSILICON). Нужен аудит всех 25 и замена.
2. **Разрешение.** Полноширинные блоки (`.phero`, `.photoband`) используют
   только `head.jpg` и `foot.jpg` (1920px) и `about1-3.jpg` (800px) — последние
   на широких экранах тянутся. Фото товаров 600×600 в такие блоки ставить
   нельзя, они размазываются; в карточках и плитках отраслей они работают.
   Для продакшена нужны исходники от 1920px.
3. **Форма** имитирует отправку (`setTimeout` в `assets/site.js`). GitHub Pages
   статический, так что нужен внешний обработчик — Formspree, Getform,
   Cloudflare Worker или почтовый эндпоинт на своём хостинге.
4. **Карта** — абстрактная SVG-схема, не настоящая.
5. **Версия TR** не сделана, переключатель ведёт на `arc-trading.com/tr/`.
6. В названии газовой позиции на боевом сайте опечатка: `KRYPTONOXENONE
   MIXTURE` вместо KRYPTON-XENON. Перенесено дословно.
