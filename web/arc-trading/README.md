# ARC Trading — редизайн главной страницы (светлая тема)

Прототип нового сайта arc-trading.com. Один самодостаточный файл: `index.html`.
Задание, по которому он сделан, — `REDESIGN-PROMPT.md`.

## Запуск

```
cd web/arc-trading
npx http-server -p 8099 -s      # или любой статический сервер
```

Открыть http://127.0.0.1:8099/

## Что внутри

Светлая палитра `#FFFFFF / #F6F7F9 / #EDEFF2`, единственный акцент — янтарный
`#F5A623` из логотипа, графит `#141922` только в футере. Шрифты Inter Tight +
Inter.

Секции повторяют текущий сайт один в один: Home → About us → Our products →
Key advantages → Contact → футер. Весь текст, цифры мощностей и контакты
перенесены дословно.

На главной каталог показывает **6 избранных позиций** (REBAR, WIRE ROD,
HRS PLATE, PIG IRON, FERROSILICON, COKE PRODUCTS) и две кнопки на полный
каталог `/service/`. Все 25 позиций остаются в массиве `PRODUCTS` внутри
`index.html` — достаточно поменять `FEATURED`, чтобы сменить витрину, или
отрисовать весь массив на странице каталога.

Эффекты: прелоадер с SVG-обводкой логотипа, шторка перехода между страницами,
прогресс-бар чтения, кастомный курсор с magnetic-кнопками, посимвольная
анимация заголовка, параллакс фона и коллажа, scroll-reveal со стаггером,
бегущая строка со всеми 25 товарами, 3D-tilt карточек, count-up счётчики,
нумерованные строки 01–05, floating-label форма с
состояниями loading → check, копирование контактов в буфер, пульсирующий
маркер на карте, гигантский обводной логотип в футере.

`prefers-reduced-motion` отключает всю анимацию.

## Что нужно доделать при интеграции

1. **Изображения хотлинкаются с боевого arc-trading.com** (`/img/u1.jpg` …
   `/img/u25.jpg`, `head.jpg`, `about1-3.jpg`). Для продакшена — положить
   локально, пережать в WebP/AVIF. Часть исходников идёт с водяными знаками
   Shutterstock (`u3` HRS PLATE, `u13` FERROSILICON) — их нужно заменить.
2. **Форма** сейчас имитирует отправку (`setTimeout`). Подключить реальный
   обработчик в `#form` submit.
3. **Карта** — абстрактная SVG-схема. При желании заменить на реальную карту в
   светлом стиле.
4. **Версия TR** — переключатель ведёт на `/tr/`, страница не входит в этот
   прототип.
5. В названии газовой позиции на боевом сайте опечатка: `KRYPTONOXENONE
   MIXTURE` (должно быть KRYPTON-XENON). Перенесено дословно — исправлять
   только по решению заказчика.
